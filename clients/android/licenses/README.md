# Client notice sources

`jni-sys-macros` license files are copied from the root of jni-rs/jni-sys at
commit `64d77b7a5f119d7b55b4e2c169a4668067ff59e6`, the crate's own VCS metadata.
The matrix-pickle notices reuse the existing diagnostic's pinned license copy.
cesu8 includes its `COPYRIGHT-RUST.txt`; its packaged README states that new
code is under the same Apache/MIT terms. All applicable copyright/notice texts
are bundled, with full Apache/MIT license texts present in the combined notices.

The packager follows the locked graph filtered for aarch64-linux-android, rather
than accidentally requiring license files for unlinked UEFI/Windows packages.
This records source/provenance, not independent legal approval.
