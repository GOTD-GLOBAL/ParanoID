# Every caption this client shows, and where each one comes from.
#
# `clients/ios/test_ui_contract.py` reads this file and checks two things:
#   * the caption is present, character for character, in the Swift sources;
#   * a caption with an Android origin is present in that Android source too.
# A caption cannot drift from the phone a fingerprint is compared against, and
# a screen cannot quietly lose one.
#
# Format: `<origin> "<caption>"`, one per line. The caption is the exact text
# of a Swift string literal, so `\n` is written the way Swift writes it and a
# significant leading or trailing space is inside the quotes. A fragment of an
# interpolated caption stands for the whole (`"Сообщение слишком длинное: "`).
#
# Origins:
#   MainActivity.java, TextEngine.java, DialogPolicy.java,
#   MessagePresentation.java, QrScanActivity.java
#       clients/android/src/org/paranoid/text/<file>; the wording is Android's
#       and this client repeats it.
#   ios
#       a screen Android does not have (the frozen screen, the stand guard, the
#       contact-flow alert) or the foreground rule of this client, whose wording
#       is the approved mock-up's. iOS has no background delivery and no in-app
#       update check, so «Получать в фоне», «Проверить обновления» and
#       «Доступна версия …» have no counterpart here and are absent by design.
