# External standards and methods

These sources inform the documentation system. They do not override accepted
ParanoID requirements or decisions.

- [Diataxis](https://diataxis.fr/): tutorials, how-to guides, reference, and
  explanation as distinct forms serving distinct reader needs.
- [C4 model](https://c4model.com/): hierarchical architecture maps using context,
  container, component, and optional code views.
- [Architectural Decision Records](https://adr.github.io/): durable records of
  significant decisions, rationale, trade-offs, and consequences.
- [MADR](https://adr.github.io/madr/): a structured Markdown ADR format.
- [NIST Secure Software Development Framework](https://csrc.nist.gov/pubs/sp/800/218/final):
  secure development practices integrated into the lifecycle.
- [OpenAPI Specification](https://spec.openapis.org/oas/): machine-readable HTTP
  API contracts.
- [Semantic Versioning](https://semver.org/): compatibility meaning for public
  version numbers.
- [Keep a Changelog](https://keepachangelog.com/en/2.0.0/): curated, human-readable
  release history.
