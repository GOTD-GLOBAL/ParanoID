# A. Runtime implementation and offline suite — sound

**Contract fidelity.** `_read_systemd_copy` selects the layout from `fstat` uid/mode *before* any ACL syscall (closure #3): root+0550 → `_require_acl(…,5)`; euid+0500 → no ACL call; everything else rejects. File pairing is enforced by the same flag (`uid == 0 if acl_layout else uid`, `mode == 0o440 if acl_layout else 0o400`), so both mixed pairs are structurally impossible. `_require_acl` compares the complete ordered 5‑tuple against the measured observation, with `0xffffffff` for undefined IDs and `GROUP_OBJ/OTHER = 0`. `_read_acl` is one fixed 44‑byte `fgetxattr` with explicit `c_int/c_char_p/c_void_p/c_size_t → c_ssize_t`, `CDLL(None, use_errno=True)`, symbol check, and rejection of any length ≠ 44 — no discovery, retry or library search.

Three properties are stronger than the design required and worth recording:
- `st_mode` equality (`== 0o550` / `== 0o440`) is on `S_IMODE`, so setuid/setgid/sticky are excluded, not just permission bits.
- The post‑read `_metadata_identity` recheck includes `st_ctime_ns`, which also catches an ACL/mode mutation between check and read — the ACL is not re‑read, but a change to it cannot go unnoticed.
- Accepting nonzero owning GID is correct: with a named USER entry present the group mode bits *are* the MASK, and `GROUP_OBJ = 0` makes the owning group's effective permission zero regardless of GID.

`read_systemd_secret()` takes no path argument, requires nonzero euid and both literal env values, and traverses `/` → `run` → `credentials` → `paranoid-turn.service` with single‑component `dir_fd` opens under `O_DIRECTORY|O_NOFOLLOW|O_CLOEXEC`, ancestors root‑owned with `& 0o7022 == 0`, all fds held via `ExitStack` (closed LIFO). `main()` calls it for **both** `check` and `run`.

## Blocking amendments (resolve, re‑freeze, then run once)

**B1 — the generated helper has never been executed.** `test_credential_matrix.py` only `ast.parse`s it. A single typo or `NameError` in `HELPER_MAIN`'s manifest parsing, traversal loop or envelope printing burns the one permitted run. Add an **offline, unprivileged, no‑systemd** test that runs the generated helper in a subprocess against a temp fixture in the fallback shape (uid‑owned 0500 dir, 0400/64‑byte file, 0400 manifest, `CREDENTIALS_DIRECTORY`/`RUNTIME_DIRECTORY` set to the fixture paths, killed after the accepted line): assert the exact accepted envelope and, for a `b'G'*64` variant, the exact `{'stage':'credential_primitive','category':'format'}` envelope and exit 2. This needs no privilege and directly de‑risks the one‑shot run.

**B2 — a stop currently yields no diagnostic.** In the positive path `live()` raises before `case['output']` or `case['properties']` are ever recorded, so `actual_primitive_not_accepted` reaches `result.json` with no stage and no metadata; the rejected envelope is closed to four fields. Combined with run‑once, a layout that differs from prediction produces an unactionable stop. Amendments: (a) record `case['output']` and `case['properties']` into the report and `save()` before every raise in `live()`; (b) at stage `credential_primitive`, allow the bounded non‑secret numerics the already‑approved metadata helper emitted — dir/file uid, mode, nlink, size, `acl_size`, `acl_errno`, `entry_count` — with the same closed schema validation in `parse_line`. These are metadata, not credential material, and were published in the prior approved observation.

## Recommended (not blocking)

**B3 — the user‑manager credential path is a prediction.** `/run/user/<uid>/credentials/<unit>.service` is pinned by manifest equality; if systemd places it elsewhere the case fails at `identity_paths` with the observed value discarded. Include the observed `CREDENTIALS_DIRECTORY` (a fixture path, not secret) in the rejected envelope, or check `Path(credential_dir).exists()` immediately after start and record the miss.
