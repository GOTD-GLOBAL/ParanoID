## REQUEST_CHANGES

Fresh-context advisory AI review under ADR-0003—not a human security audit. **Two blocking findings:**

1. **Installed mode-0755 application unit prevents every due renewal.**
   `deploy/tls_renewal.py:51,189` reads `ROOT/paranoid-alpha.service` with the default `private=True`, requiring mode **0600**. The supplied real-host unit is **0755**. Synthetic reproduction using that mode returned `ValueError: unsafe file` before lifecycle actions. Existing tests conceal this by creating the unit as 0600.
   **Required:** use the non-group/world-writable public-source checks for both unit reads, retaining owner/type/symlink/hardlink guards; add mode-0755 coverage through both `baseline()` and real `SystemOps.guard()`. Correct `docs/operations/tls-auto-renewal.md:17`, which incorrectly requires the existing unit to be 0600. Do not chmod the deployed unit to accommodate the bug.

2. **First-install script does not enforce its no-renewal gate before starting automation.**
   `/tmp/paranoid-auto-renew-install.py:39–48` records `--check` output but never requires `result == "not_due"`. A valid `"due"` result proceeds into the actual oneshot, permitting certificate replacement and application restart. The installer also enables the persistent timer **before** comparing the before/after certificate/config/release/PID baseline. Detection afterward cannot undo an unauthorized first-install restart.
   **Required:** parse and require `not_due` before the oneshot; require successful oneshot and unchanged baseline **before** timer enablement. Align runbook steps 4–5 with this ordering.
