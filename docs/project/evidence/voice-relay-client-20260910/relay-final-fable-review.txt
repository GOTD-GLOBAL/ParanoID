## Relay-publication proposal — design disposition

**Coherent and approved as a design direction, conditional on explicit constraints; no code is applied or credited.** The proposal (relay-only: publish ONE immutable full local SDP snapshot after a usable relay candidate exists, with ~500 ms bounded coalescing; direct mode retains COMPLETE) targets exactly the measured VOICE-PUB-01 mechanism and preserves the non-trickle authenticated-SDP contract. Required safety constraints before implementation:

1. Snapshot only after `setLocalDescription` success, taken on the media owner thread, containing ≥1 relay `a=candidate` line for the single bundled component; retain the existing empty-SDP and 6144-byte guards.
2. Idempotence: `localPublished` set once; later candidates, gathering-state changes, and the eventual COMPLETE must never republish or mutate what was sent; tests must assert fingerprint/ice-ufrag/ice-pwd equality between the snapshot and any later local description (no drift affecting authenticated media parameters or `offerDigest`).
3. The coalescing timer lives on the worker handler, is cancelled by close/`fail`/generation supersession, and can never fire after cleanup or capture audio post-cancellation.
4. Offer/answer symmetry (both `createOffer` and `createAnswer` paths in relay mode); direct-mode behavior byte-identical to today.
5. If no usable relay candidate arrives, the existing controller deadline terminates the call — no new fallback.

Mandatory closure tests: the existing publication-latency RED turned GREEN; ordinary full-app both-relay failing-before/passing-after interop with real issuer, E2EE, decoded tone, and cleanup; direct-compatibility regression; cancellation-during-coalescing, late-gather-ignored, and duplicate-publication negatives; receiving-side strict non-trickle parser compatibility; then a fresh source/artifact closure review. Note plainly: this proposal is justified by the measured publication delay; it is **not** proven to resolve the earlier incoming failures, and only the failing-before/passing-after test can make that claim.
