## Lifecycle

1. Discuss significant designs in `docs/rfcs/`.
2. Create an ADR when a decision is ready to accept.
3. Link requirements, threat analysis, experiments, and the accepted RFC.
4. Add the ADR to this index.
5. Supersede an accepted ADR with a new ADR rather than rewriting history.

Use [the ADR template](adr-template.md) for new decisions.
